# Thread cards (3D print)

Dainty bobbin-style thread cards with a scalloped bottom edge, for the beginner kit.

| File | Threads | Size (mm) |
|---|---|---|
| `stl/thread_card_2_threads.stl` | 2 | 46 × 71.5 × 1.6 |
| `stl/thread_card_3_threads.stl` | 3 | 46 × 94.5 × 1.6 |
| `stl/thread_card_4_threads.stl` | 4 | 46 × 117.5 × 1.6 |
| `stl/thread_card_5_threads.stl` | 5 | 46 × 140.5 × 1.6 |

Features: hanging hole, shallow recessed label panel (sticker spot, 32 × 7 mm),
thread-catch slits with a V lead-in on every divider to tuck the thread ends.

**Printing:** lay flat, no supports, 0.2 mm layers, 100% infill (thin part), PLA or PETG.
Print the label side up so the recess is crisp.

To change sizes (thickness, number of scallops, etc.) edit the constants at the top of
`make_thread_cards.py` and run `python3 make_thread_cards.py`.
